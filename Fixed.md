# Исправления по замечаниям

## WhiteNoise
Настроена раздача статических файлов через WhiteNoise.
В Dockerfile выполняется `collectstatic`.

## WebSocket
Добавлена отправка данных магазина через WebSocket:
- при создании магазина;
- при изменении магазина.

Для проверки добавлен `ws_client.py`.

## Middleware
Исправлено логирование API:
- записывается название API-метода;
- Swagger и JWT endpoints не логируются как API-методы.

## Docker
Исправлен запуск приложения в Docker:
- Daphne запускается на `0.0.0.0:8000`;
- выполняются миграции;
- выполняется `collectstatic`;
- настроен `ALLOWED_HOSTS`.

## Swagger
Расширена документация:
- GET `/api/organizations/`;
- GET `/api/organizations/{id}/shops_file/`;
- PUT `/api/shops/{id}/`.

Добавлены описания параметров и ответов.

## PUT магазина
Исправлена обработка несуществующего магазина:
- возвращается HTTP 404 вместо 500.

## Тесты
Добавлены автоматические тесты API:
- авторизация;
- получение организаций;
- исключение удалённых магазинов;
- обновление магазина;
- валидация `index`;
- обработка 404;
- проверка JWT-доступа.
